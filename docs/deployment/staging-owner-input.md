# Staging owner input sheet

Only information the owner must supply. Engineering work, verification, and
anything derivable from the repository are not listed. Never put secrets in
this file, in Git, or in chat: secrets go straight into the secret store or
the provider dashboard.

## OWNER INPUT NOW

**None.** The prototype stays on the Supabase Free plan, and staging
provisioning is on hold. Nothing has to be supplied or decided today.

Optional, if the owner wants to shorten the later steps: choose the domain.
It is still not required now.
